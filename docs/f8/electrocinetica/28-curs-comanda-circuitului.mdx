:::tip De reținut

Există **două tipuri** de buton-apăsător: butonul **deschis în repaus** și
butonul **închis în repaus**.

Butonul-apăsător îngăduie deschiderea sau închiderea unui circuit electric în
chip **vremelnic** — adică numai cât ține apăsarea.

:::

## 6. Rezolvarea exercițiului-tip

**1.** Pe schemă se vede un organ de comandă cu **trei borne** — $\mathrm{C}$,
$\mathrm{T}$ și $\mathrm{R}$ — dintre care una este comună. Organul de comandă
folosit este deci **comutatorul**.

**2.** Borna comună $\mathrm{C}$ este legată la borna $\mathrm{T}$, deci
curentul trece prin ramura lămpii $\mathrm{L}_2$: lampa electrică
$\mathrm{L}_1$ este **stinsă**, iar lampa $\mathrm{L}_2$ este **aprinsă**.

**3.** Ca fiecare lampă să aibă starea contrară, mutăm comutatorul de pe borna
$\mathrm{T}$ pe borna $\mathrm{R}$:

<FiguraManual
  src="v6-exercitiu-tip-rezolvare.png"
  lat={387}
  inalt={142}
  latime={380}
  eticheta="Aceeași schemă, cu comutatorul mutat pe cealaltă bornă: acum e aprinsă lampa L1 și stinsă L2"
  legenda="Schema refăcută: acum $L_1$ este aprinsă și $L_2$ stinsă."
/>

Lampa electrică $\mathrm{L}_1$ este acum **aprinsă**, iar lampa
$\mathrm{L}_2$ este **stinsă**.

**4.** Montajul acesta este **aprinderea alternativă a două lămpi**.

:::tip Metoda

- recunoști organul de comandă după **simbolul lui normalizat**;
- ții minte că un comutator are **trei borne** și comandă două circuite
  deosebite: închiderea sau deschiderea fiecăruia atârnă de poziția
  comutatorului;
- starea lămpii (aprinsă sau stinsă) atârnă de fiecare poziție a organului de
  comandă. Asta îți lasă să înțelegi cum merge montajul și să-l recunoști.

:::
