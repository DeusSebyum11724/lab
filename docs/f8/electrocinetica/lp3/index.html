LP3 — Verificarea legii nodurilor

Ora de lucru practic

Se lucrează pe noțiunile din C3 — Legea nodurilor. Patru probe, cu timpul de lucru al fiecăreia; în total 45 de minute.

1. Care situație este posibilă​

Timp de lucru: 10 minute.

Dintre situațiile următoare, una singură este posibilă. Care?

Rezolvare

Răspunsul c. Trebuie ca suma intensităților ramurilor din stânga să fie egală cu suma intensităților curenților din ramurile din dreapta.

Să detaliem afirmația asta. Numim A nodul din stânga și B nodul din dreapta. Aplicăm legea nodurilor în nodul A. Curenții care merg spre nod sunt I1I_1I1​ și I2I_2I2​, iar cel care pleacă din el este III. Avem deci:

I=I1+I2I = I_1 + I_2I=I1​+I2​

Aplicăm acum legea nodurilor în nodul B. Curentul care merge spre nod este III, iar cei care pleacă sunt I3I_3I3​ și I4I_4I4​. Avem deci:

I3+I4=II_3 + I_4 = II3​+I4​=I

Fiindcă I=I1+I2I = I_1 + I_2I=I1​+I2​ și I=I3+I4I = I_3 + I_4I=I3​+I4​, avem într-adevăr:

I1+I2=I3+I4I_1 + I_2 = I_3 + I_4I1​+I2​=I3​+I4​

egalitate pe care numai figura c o satisface: 2+3=4+12 + 3 = 4 + 12+3=4+1.

Aici natura componentelor contează prea puțin: becul și rezistorul se comportă la fel față de legea nodurilor.

Un alt fel de a proceda este să observăm că fiecare dintre circuitele propuse este echivalent cu un circuit care are un nod unic:

și atunci se vede că trebuie neapărat să avem I1+I2=I3+I4I_1 + I_2 = I_3 + I_4I1​+I2​=I3​+I4​.

2. Calculul unor intensități​

Liceul Henri IV, Paris  ·  ★★  ·  10 minute

În becurile L2L_2L2​, L3L_3L3​ și L4L_4L4​, intensitățile curentului electric sunt respectiv I2=50 mAI_2 = 50\ \text{mA}I2​=50 mA, I3=14 mAI_3 = 14\ \text{mA}I3​=14 mA și I4=9,0 mAI_4 = 9{,}0\ \text{mA}I4​=9,0 mA.

1. Care este valoarea intensității curentului care circulă prin becul L5L_5L5​?

2. Care este valoarea intensității curentului care circulă prin becul L1L_1L1​?

3. Care este valoarea intensității curentului din ramura principală (cea a pilei)?

Rezolvare

1. Intensitatea este peste tot aceeași într-o ramură dată, deci intensitatea care parcurge becul L5L_5L5​ este I4I_4I4​, adică 9,0 mA9{,}0\ \text{mA}9,0 mA.

2. Căutăm intensitatea I1I_1I1​. Aplicăm legea nodurilor în punctul B. Ea se scrie:

I1=I3+I4I_1 = I_3 + I_4I1​=I3​+I4​

adică:

I1=14+9,0=23 mAI_1 = 14 + 9{,}0 = 23\ \text{mA}I1​=14+9,0=23 mA

3. Căutăm valoarea intensității III. Legea nodurilor în punctul A se scrie:

I=I1+I2I = I_1 + I_2I=I1​+I2​

adică:

I=23+50=73 mAI = 23 + 50 = 73\ \text{mA}I=23+50=73 mA

3. Calcul de intensitate​

Liceul Louis-le-Grand, Paris  ·  ★★★  ·  10 minute

Se consideră circuitul reprezentat mai jos. Ampermetrul de pe ramura becului dă o citire de trei ori mai mare decât celălalt ampermetru. Știind că I=2,5 AI = 2{,}5\ \text{A}I=2,5 A și I2=0,50 AI_2 = 0{,}50\ \text{A}I2​=0,50 A, determină intensitatea curentului care circulă prin bec.

Rezolvare

Reproducem și adnotăm figura dată în enunț. Numim I′I'I′ intensitatea din porțiunea de fir dintre nodurile A și B. Legea nodurilor în A se scrie:

I=I1+I′I = I_1 + I'I=I1​+I′

Pe de altă parte, legea nodurilor în B se scrie:

I′=I2+I3I' = I_2 + I_3I′=I2​+I3​

Înlocuind I′I'I′ cu expresia asta în prima egalitate, avem:

I=I1+I2+I3I = I_1 + I_2 + I_3I=I1​+I2​+I3​

Putem scrie egalitatea asta și direct, dacă observăm că circuitul este echivalent cu circuitul următor și aplicăm legea nodurilor în C:

Ampermetrul din stânga măsoară intensitatea I1I_1I1​, iar cel din dreapta măsoară intensitatea I3I_3I3​. Indicațiile din enunț implică:

I3=3 I1I_3 = 3\,I_1I3​=3I1​

deci:

I=I33+I2+I3=43 I3+I2I = \frac{I_3}{3} + I_2 + I_3 = \frac{4}{3}\,I_3 + I_2I=3I3​​+I2​+I3​=34​I3​+I2​

deci:

I3=34 (I−I2)I_3 = \frac{3}{4}\,(I - I_2)I3​=43​(I−I2​)

Aplicația numerică dă:

I3=34×2,0=1,5 AI_3 = \frac{3}{4} \times 2{,}0 = 1{,}5\ \text{A}I3​=43​×2,0=1,5 A

Intensitatea curentului prin bec este 1,5 A1{,}5\ \text{A}1,5 A.

4. Legea nodurilor​

Liceul Chateaubriand, Rennes  ·  ★★★  ·  15 minute

1. Enunță legea nodurilor.

2. Un circuit electric are înfățișarea de mai jos.

Se dau relațiile:

I1=I4I2=4 I4I=3,7 AI_1 = I_4 \qquad I_2 = 4\,I_4 \qquad I = 3{,}7\ \text{A}I1​=I4​I2​=4I4​I=3,7 A

Deduce valoarea intensității curentului din fiecare ramură.

Rezolvare

1. Suma intensităților curenților care merg spre nod este egală cu suma intensităților curenților care pleacă din nod.

2. Am trecut intensitatea III și în partea de jos-stânga, fiindcă intensitatea este aceeași într-o ramură dată (vezi cursul).

Legea nodurilor în nodul A se scrie:

I=I1+I2I = I_1 + I_2I=I1​+I2​

iar în nodul B se scrie:

I2=I3+I4I_2 = I_3 + I_4I2​=I3​+I4​

Dar I2=4I4I_2 = 4I_4I2​=4I4​, deci:

4I4=I3+I44I_4 = I_3 + I_44I4​=I3​+I4​

de unde deducem:

3I4=I33I_4 = I_33I4​=I3​

Avem deci:

I=I1+I3+I4=I4+I3+I4=5I4I = I_1 + I_3 + I_4 = I_4 + I_3 + I_4 = 5I_4I=I1​+I3​+I4​=I4​+I3​+I4​=5I4​

adică:

I4=I1=I5,I3=3 I5,I2=4 I5I_4 = I_1 = \frac{I}{5}, \qquad I_3 = 3\,\frac{I}{5}, \qquad I_2 = 4\,\frac{I}{5}I4​=I1​=5I​,I3​=35I​,I2​=45I​

Putem verifica faptul că avem într-adevăr:

I=I1+I2=I5+4 I5I = I_1 + I_2 = \frac{I}{5} + 4\,\frac{I}{5}I=I1​+I2​=5I​+45I​

Aplicația numerică dă:

I1=I4=0,74 AI_1 = I_4 = 0{,}74\ \text{A}I1​=I4​=0,74 AI2=4×0,74=3,0 AI_2 = 4 \times 0{,}74 = 3{,}0\ \text{A}I2​=4×0,74=3,0 AI3=3×0,74=2,2 AI_3 = 3 \times 0{,}74 = 2{,}2\ \text{A}I3​=3×0,74=2,2 A
