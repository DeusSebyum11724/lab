C7 — Mărirea și modelul ochiului

Planul orei
  1. Mărirea
  2. Semnul măririi
  3. Mărirea și triunghiurile asemenea
  4. Rezolvarea exercițiului-tip

1. Mărirea​

După poziția obiectului și după distanța focală a lentilei, imaginea poate fi mai mare sau mai mică. Ca să măsurăm efectul ăsta, introducem noțiunea de mărire.

Definiția 2

Se numește mărire, și se notează cu γ\gammaγ (litera grecească „gama”), mărimea pentru care:

∣γ∣=A′B′AB|\gamma| = \frac{\mathrm{A'B'}}{\mathrm{AB}}∣γ∣=ABA′B′​

Modulul măririi este deci câtul dintre mărimea imaginii și mărimea obiectului.

  • Dacă ∣γ∣>1|\gamma| > 1∣γ∣>1, imaginea este mai mare decât obiectul.
  • Dacă ∣γ∣<1|\gamma| \lt 1∣γ∣<1, imaginea este mai mică decât obiectul.
Atenție

Mărirea, fiind câtul a două lungimi, este un număr fără unitate de măsură. Trebuie bineînțeles ca cele două lungimi să fie evaluate în aceleași unități — de exemplu amândouă în milimetri — ca să iasă un rezultat corect.

2. Semnul măririi​

Prin convenție, γ\gammaγ este pozitiv dacă imaginea este în același sens cu obiectul — se spune atunci că imaginea este dreaptă — și negativ dacă imaginea este în sens opus obiectului — se spune atunci că imaginea este răsturnată.

De reținut

Modulul lui γ\gammaγ spune de câte ori este imaginea mai mare sau mai mică decât obiectul. Semnul lui γ\gammaγ spune dacă imaginea este dreaptă sau răsturnată.

Așa, dacă γ<0\gamma \lt 0γ<0, imaginea este răsturnată: ea stă, față de obiect, „cu capul în jos".

3. Mărirea și triunghiurile asemenea​

Raza care trece prin centrul optic O nu este deviată: ea leagă vârful B al obiectului de vârful B′\mathrm{B'}B′ al imaginii, trecând prin O.

Dreptele (AB)(\mathrm{AB})(AB) și (A′B′)(\mathrm{A'B'})(A′B′) sunt paralele — amândouă sunt perpendiculare pe axa optică. Triunghiurile OAB\mathrm{OAB}OAB și OA′B′\mathrm{OA'B'}OA′B′ sunt deci asemenea, iar teorema lui Thales, așa cum ai învățat-o la matematică, se scrie aici:

OA′OA=A′B′AB=∣γ∣\frac{\mathrm{OA'}}{\mathrm{OA}} = \frac{\mathrm{A'B'}}{\mathrm{AB}} = |\gamma|OAOA′​=ABA′B′​=∣γ∣

Relația asta este utilă: dacă știm mărirea și distanța de la obiect la lentilă, aflăm distanța de la lentilă la imagine, și invers.

4. Rezolvarea exercițiului-tip​

Reluăm montajul de la ora C5, reprezentat la scara 1:1, și răspundem la ultima întrebare: care este mărirea dată de montajul ăsta?

Mărirea este dată de:

∣γ∣=A′B′AB|\gamma| = \frac{\mathrm{A'B'}}{\mathrm{AB}}∣γ∣=ABA′B′​

Aici avem A′B′=15 mm\mathrm{A'B'} = 15\ \text{mm}A′B′=15 mm și AB=30 mm\mathrm{AB} = 30\ \text{mm}AB=30 mm, deci mărirea este:

∣γ∣=1530=12|\gamma| = \frac{15}{30} = \frac{1}{2}∣γ∣=3015​=21​

Imaginea este răsturnată, deci:

γ=−12\gamma = -\frac{1}{2}γ=−21​

5. Modelul ochiului​

Ochiul este un organ extrem de perfecționat. El cuprinde numeroase elemente; vederea în secțiune de mai jos le arată pe cele principale.

Cristalinul joacă rolul unei lentile subțiri convergente. Razele care ies din el ajung la retină, unde se formează imaginile obiectelor aflate în fața ochiului. Retina joacă, într-un fel, rolul unui ecran.

Un model foarte simplificat al ochiului este deci următorul.

Ora următoare

LP7 — Mărirea și modelul ochiului Obținem imaginea pe ecran, măsurăm obiectul și imaginea, calculăm mărirea și studiem cazul obiectului așezat la distanța dublă față de distanța focală.
