# C10 — Focarele lentilei. Obiect și imagine

:::info Planul orei

1. Ce este o lentilă convergentă
2. Cele două focare
3. Obiect real, obiect virtual
4. Imagine reală, imagine virtuală
5. Cele trei raze remarcabile

:::

---

## 1. Ce este o lentilă convergentă

Lentilele subțiri convergente sunt obiecte transparente, **mai groase în
centrul lor decât la marginile lor**, pe care le presupunem simetrice față de
o axă numită **axă optică**.

Lentila convergentă $(L)$ se simbolizează printr-o **săgeată dublă**.

---

## 2. Cele două focare

Lentilele convergente sunt caracterizate prin:

- **centrul optic** $O$ — intersecția lentilei cu axa optică;
- **focarul imagine** $F'$ — punctul în care converg razele care ajung pe
  lentilă **paralel cu axa optică**;
- **focarul obiect** $F$ — simetricul lui $F'$ față de $O$, din care pleacă
  razele care ies din lentilă **paralel cu axa optică**;
- **distanța focală imagine** $f' = OF'$;
- **planul focal imagine** $(\Pi')$, care trece prin $F'$ perpendicular pe axa
  optică;
- **planul focal obiect** $(\Pi)$, care trece prin $F$ perpendicular pe axa
  optică.

la dreapta, la aceeași distanță $f'$.

## 3. Obiect real, obiect virtual

:::danger Definiția 1

Un **obiect** $A$ este un punct de intersecție al razelor care se îndreaptă
**spre** lentilă. Când razele se pot întâlni cu adevărat, obiectul este
**real**; când se întâlnesc numai prelungirile razelor, obiectul este
**virtual**.

## 4. Imagine reală, imagine virtuală

:::danger Definiția 2

O **imagine** $A'$ este un punct de intersecție al razelor care **ies** din
lentilă. Din nou, imaginea este **reală** dacă razele converg cu adevărat în
$A'$; imaginea este **virtuală** dacă numai prelungirile razelor se taie în
$A'$.

:::

:::warning Atenție

O imagine **reală** se poate prinde pe un ecran, fiindcă lumina ajunge cu
adevărat acolo. O imagine **virtuală** nu se poate prinde pe ecran: acolo nu
ajunge nicio rază, ochiul doar **crede** că lumina vine de acolo.

:::

## 5. Cele trei raze remarcabile

<FiguraManual
  src="r7-trei-raze.png"
  lat={360}
  inalt={200}
  latime={330}
  eticheta="Cele trei raze remarcabile ale unei lentile convergente"
  legenda="Raza (1) trece prin O nedeviată; raza (2) intră paralelă și iese prin F′; raza (3) pleacă din F și iese paralelă."
/>

Cele trei raze se pot folosi ca să afli poziția imaginii $B'$ a unui obiect $B$
care nu se află pe axa optică.

*Observație*: în practică, **două** dintre razele remarcabile sunt de ajuns, în
afară de cazul în care enunțul cere altfel.

:::tip Metoda — imaginea unui punct B din afara axei

- trasezi raza $(1)$, plecată din $B$, care traversează $(L)$ prin $O$ **fără
  să fie deviată**;
- trasezi raza $(2)$, plecată din $B$, care ajunge pe $(L)$ **paralel cu axa
  optică**; raza asta iese din $(L)$ trecând prin $F'$;
- intersecția celor două raze care ies din $(L)$ coincide cu imaginea $B'$: ori
  $B'$ este reală (cele două raze se taie **în spatele** lentilei), ori $B'$
  este virtuală (trebuie să trasezi prelungirile razelor ca să se taie, **în
  fața** lentilei).

:::
