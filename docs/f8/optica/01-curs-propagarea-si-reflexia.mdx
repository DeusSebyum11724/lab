# C1 — Propagarea luminii și reflexia

:::info Planul orei

1. Propagarea rectilinie și raza de lumină
2. Normala și planul de incidență
3. Reflexia luminii

:::

---

## 1. Propagarea rectilinie și raza de lumină

Într-un mediu omogen, lumina se propagă în linie dreaptă.

Folosind diafragme destul de mici, putem obține fascicule de lumină aproape
asimilabile unor segmente de dreaptă. Acestea materializează **razele de
lumină**.

<FigFascicul />

:::danger Definiția 1

Un **fascicul luminos** corespunde unui ansamblu de raze luminoase.

:::

:::tip De reținut

Într-un mediu omogen lumina merge drept. Raza de lumină este modelul cu care
desenăm drumul ei: o linie dreaptă cu o săgeată care arată în ce sens merge
lumina.

:::

---

## 2. Normala și planul de incidență

Punctul în care raza atinge o suprafață se numește **punct de incidență**.

:::danger Definiția 2

Numim **normală** la o suprafață dreapta perpendiculară pe suprafață, dusă prin
punctul de incidență.

:::

:::danger Definiția 3

Numim **plan de incidență** planul perpendicular pe suprafață care conține raza
incidentă.

:::

Planul de incidență conține raza incidentă și normala la suprafață. În desenele
noastre, planul de incidență este chiar planul foii.

**Unghiul de incidență** $i_1$ este unghiul dintre raza incidentă și normală.

<FigNormala />

:::warning Atenție

Unghiul de incidență se măsoară **față de normală**, niciodată față de
suprafață. Dacă raza cade perpendicular pe suprafață, unghiul de incidență este
$0^\circ$, nu $90^\circ$.

:::

---

## 3. Reflexia luminii

O rază luminoasă se reflectă pe o oglindă. Se spune că raza luminoasă suferă o
**reflexie**.

Când suprafața este transparentă — de pildă suprafața apei sau a unei plăci de
sticlă — reflexia poate fi **parțială**: o parte din lumină se întoarce, iar
cealaltă trece mai departe. De partea care trece ne vom ocupa la orele
următoare.

:::tip De reținut — legile reflexiei

1. Raza reflectată și raza incidentă sunt în planul de incidență.
2. Unghiul de incidență $i_1$ este egal cu unghiul de reflexie $r$.

:::

<FigReflexie />

Cele două legi înseamnă, împreună, că raza reflectată este trimisă înapoi în
direcția simetrică față de normală. Ea nu se întoarce pe drumul pe care a venit,
decât atunci când cade perpendicular pe oglindă.

---

:::note Ora următoare

**LP1 — Legile reflexiei.** Verificarea legilor reflexiei pe un disc gradat, cu
raportorul, și problema oglinzii înclinate la $45^\circ$.

:::
