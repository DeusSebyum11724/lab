# Curs VI

Primul an de fizică. Capitolele de mai jos sunt cele din programa școlară și
sunt deja pregătite ca rubrici; fiecare apare în bara laterală odată cu prima
lecție scrisă în el.

- **Introducere în studiul fizicii**
- **Concepte de bază în fizică**
- **Mecanică**
- **Fenomene termice**
- **Fenomene electrice și magnetice**
- **Fenomene optice**
