C4 — Reprezentarea grafică a măsurătorilor

Planul orei
  1. Introducere
  2. Cele două axe
  3. Scara
  4. Marcarea punctelor
  5. Trasarea curbei
  6. Titlul și citirea graficului
  7. Rezolvarea exercițiului-tip

1. Introducere​

Un grafic se construiește din valori măsurate. El arată cum se schimbă o mărime în funcție de alta.

Se cere construit graficul care arată cum se schimbă temperatura apei în funcție de timp. Se ia: 111 centimetru pentru 111 minut pe abscisă și 111 centimetru pentru 20 ∘C20\ ^\circ\text{C}20 ∘C pe ordonată.

1. Care mărime se pune pe axa orizontală și care pe cea verticală?

2. Cum se marchează fiecare pereche de măsurători?

3. Cum se trage curba?

4. Ce se vede pe grafic după minutul al cincilea?

Îl lăsăm deocamdată deoparte și îl reluăm la sfârșitul orei.

2. Cele două axe​

Se trag cu rigla două axe perpendiculare, fiecare cu o săgeată la capăt:

  • axa verticală este axa ordonatelor;
  • axa orizontală este axa absciselor.

Fiecare axă se numește: se scrie pe ea mărimea și unitatea ei.

De reținut

Pe axa orizontală se pune mărimea care se schimbă de la sine — de obicei timpul. Pe cea verticală se pune mărimea care depinde de ea.

3. Scara​

Scara spune cât înseamnă un centimetru pe fiecare axă. Ea se alege sau se dă în enunț.

Înainte de gradare se caută valorile cele mai mari din tabel, ca axele să fie destul de lungi ca să le cuprindă. Aici temperatura urcă până la 100 ∘C100\ ^\circ\text{C}100 ∘C, iar timpul până la 101010 minute; cu scara dată, axele trebuie să aibă cel puțin 555 și, respectiv, 101010 centimetri.

4. Marcarea punctelor​

Din tabelul de măsurători, fiecare pereche se marchează printr-o cruce.

De pildă, la minutul 111 temperatura apei este de 32 ∘C32\ ^\circ\text{C}32 ∘C: se marchează perechea (1 min ; 32 ∘C)(1\ \text{min}\ ;\ 32\ ^\circ\text{C})(1 min ; 32 ∘C).

Crucea este mai bună decât punctul: brațele ei arată limpede unde se taie cele două valori, iar o cruce nu se pierde sub linia curbei.

5. Trasarea curbei​

Curba se trage cu mâna liberă, trecând prin cruci.

Atenție

Nu se trage niciodată o linie frântă, legând două cruci alăturate prin segmente. Măsurătorile au fiecare o mică nesiguranță; curba trebuie să treacă cât mai aproape de cât mai multe cruci, nu neapărat prin fiecare.

Rigla se folosește pentru legarea crucilor numai dacă ele sunt așezate în linie dreaptă.

6. Titlul și citirea graficului​

La urmă se dă un titlu graficului. Titlul spune ce mărime este înfățișată și în funcție de ce.

Graficul spune, dintr-o privire, ceva ce tabelul spune greu: temperatura urcă repede în primele cinci minute, apoi se oprește la 100 ∘C100\ ^\circ\text{C}100 ∘C și rămâne acolo, oricât ai încălzi mai departe. Palierul acesta este semnul fierberii.

7. Rezolvarea exercițiului-tip​

1. Pe axa orizontală (a absciselor) se pune timpul, în minute; pe axa verticală (a ordonatelor) se pune temperatura, în grade Celsius. Fiecare axă se numește și se gradează după scara dată.

2. Fiecare pereche de măsurători se marchează printr-o cruce. Perechile sunt (0;20)(0 ; 20)(0;20), (1;32)(1 ; 32)(1;32), (2;52)(2 ; 52)(2;52), (3;70)(3 ; 70)(3;70), (4;86)(4 ; 86)(4;86), (5;100)(5 ; 100)(5;100) și apoi (6;100)(6 ; 100)(6;100), (7;100)(7 ; 100)(7;100)… până la (10;100)(10 ; 100)(10;100).

3. Curba se trage cu mâna liberă, cât mai aproape de cât mai multe cruci. Nu se trage linie frântă și nu se folosește rigla, fiindcă punctele nu sunt așezate în linie dreaptă.

4. După minutul al cincilea, curba devine orizontală: temperatura rămâne la 100 ∘C100\ ^\circ\text{C}100 ∘C, deși încălzirea urmează. Apa a început să fiarbă, iar energia primită nu mai ridică temperatura.

Ora următoare

LP4 — Reprezentarea grafică a măsurătorilor. Patru probe: cele două axe, alegerea scării, graficul de construit și citirea unui grafic.

Înainte de ea, treci prin S4 — Reprezentarea grafică a măsurătorilor: noțiunile lecției strânse la un loc și un exercițiu rezolvat pas cu pas.
