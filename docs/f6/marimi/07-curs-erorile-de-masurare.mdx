## 1. De ce nu iese același număr de fiecare dată

Măsoară de mai multe ori lungimea unui creion cu rigla, având grijă ca de
fiecare dată să măsori corect. Vei constata că valorile obținute **nu sunt
toate egale**.

Asta nu înseamnă că ai greșit. Înseamnă că **orice măsurătoare are o
nesiguranță**, oricât de atent ai lucra. Lecția de azi arată cum se scrie corect
un rezultat, ținând seama de această nesiguranță.

## 2. Tabelul de date experimentale

Datele obținute se trec într-un **tabel de date experimentale**. Primul rând al
tabelului este **capul de tabel**: el conține simbolurile mărimilor fizice și
unitățile de măsură.

| Nr. det. | $L$ ($\text{cm}$) | $L_{\text{medie}}$ ($\text{cm}$) | $\Delta L$ ($\text{cm}$) | $(\Delta L)_{\text{medie}}$ ($\text{cm}$) |
|---|---|---|---|---|
| 1 | $9{,}8$ | | $0{,}02$ | |
| 2 | $9{,}7$ | | $0{,}08$ | |
| 3 | $9{,}7$ | $9{,}78$ | $0{,}08$ | $0{,}064$ |
| 4 | $8{,}5$ | | — | |
| 5 | $9{,}9$ | | $0{,}12$ | |
| 6 | $9{,}8$ | | $0{,}02$ | |

| Coloana | Ce conține |
|---|---|
| **1** | numerele determinărilor: $1$, $2$, $3$… |
| **2** | valorile măsurate, fără simbol și fără unitate — acestea sunt în capul de tabel |
| **3** | lungimea medie, calculată o singură dată |
| **4** | eroarea absolută a fiecărei determinări |
| **5** | eroarea absolută medie |

---

## 3. Media aritmetică și erorile grosolane

Este posibil să apară unele valori **mult diferite** de celelalte — în tabelul
nostru, $L = 8{,}5\ \text{cm}$.

:::danger Definiția 1

Valorile mult diferite de celelalte se numesc **erori grosolane**. Ele se scriu
în tabel, dar se **taie** și nu se iau în calcul.

:::

Lungimea medie $L_{\text{medie}}$ este **media aritmetică** a valorilor din
coloana a doua, fără erorile grosolane:

$$
L_{\text{medie}} = \frac{9{,}8 + 9{,}7 + 9{,}7 + 9{,}9 + 9{,}8}{5} = \frac{48{,}9}{5} = 9{,}78\ \text{cm}
$$

---

## 4. Eroarea absolută

:::danger Definiția 2

**Eroarea absolută**, notată $\Delta L$, este diferența dintre lungimea
corespunzătoare unei determinări și lungimea medie:

$$
\Delta L = L - L_{\text{medie}} \qquad\text{sau}\qquad \Delta L = L_{\text{medie}} - L
$$

în funcție de care valoare numerică este mai mare.

:::

Litera grecească $\Delta$ (delta), așezată în fața unei mărimi fizice, **este un
simbol care indică o diferență** între valorile mărimii.

Eroarea absolută se măsoară în aceeași unitate ca mărimea măsurată — aici, în
centimetri.

**Pentru exemplul nostru:**

$$
\Delta L_1 = 9{,}8 - 9{,}78 = 0{,}02\ \text{cm}
$$

$$
\Delta L_2 = 9{,}78 - 9{,}7 = 0{,}08\ \text{cm}
$$

---

## 5. Eroarea absolută medie

:::danger Definiția 3

**Eroarea absolută medie**, notată $(\Delta L)_{\text{medie}}$, este media
aritmetică a erorilor absolute.

:::

$$
(\Delta L)_{\text{medie}} = \frac{0{,}02 + 0{,}08 + 0{,}08 + 0{,}12 + 0{,}02}{5} = \frac{0{,}32}{5} = 0{,}064\ \text{cm}
$$

---

## 6. Scrierea rezultatului

:::danger De reținut

Rezultatul determinării se scrie ca **valoarea medie plus sau minus eroarea
medie absolută**:

$$
L = L_{\text{medie}} \pm (\Delta L)_{\text{medie}}
$$

:::

Se folosește **același număr de zecimale** pentru toate valorile, prin
rotunjire. Pentru exemplul nostru, cu două zecimale:

$$
L = 9{,}78\ \text{cm} \pm 0{,}06\ \text{cm}
$$

Rezultatul înseamnă că valoarea reală se află **într-un interval**:

$$
9{,}78 - 0{,}06 \le L \le 9{,}78 + 0{,}06
$$

$$
9{,}72\ \text{cm} \le L \le 9{,}84\ \text{cm}
$$

:::tip Ce spune de fapt rezultatul

Nu spune „creionul are exact $9{,}78\ \text{cm}$", ci „lungimea lui se află
undeva între $9{,}72$ și $9{,}84\ \text{cm}$". Cu cât eroarea medie e mai mică,
cu atât intervalul e mai strâns și măsurătoarea mai bună.

:::

## 7. Sursele de erori

La efectuarea unei măsurători se pot face greșeli, numite **erori de măsură**.

| Sursa | Ce se întâmplă |
|---|---|
| **lipsa de precizie a instrumentului** | diviziunile sunt prea rare pentru mărimea măsurată |
| **citirea incorectă a indicațiilor** | se privește oblic pe riglă |
| **lipsa de atenție sau de îndemânare** | capătul nu se așază în dreptul lui zero |

Existența erorilor este normală. Ca să obținem un rezultat cât mai apropiat de
valoarea adevărată, **repetăm măsurătorile** de mai multe ori și prelucrăm
datele așa cum am arătat mai sus.
