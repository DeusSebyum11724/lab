Unitățile de măsură în Sistemul Internațional

În fizică, Sistemul Internațional de Unități (SI) este sistemul de unități utilizat pentru exprimarea și măsurarea mărimilor fizice.

Sistemul Internațional are șapte unități fundamentale, fiecare corespunzând unei mărimi fizice fundamentale.

Metrul — unitatea de măsură pentru lungime​

Unitatea fundamentală pentru lungime este metrul.

[l]=m[l] = \mathrm{m}[l]=m

Metrul este utilizat pentru măsurarea:

  • lungimilor;
  • distanțelor;
  • înălțimilor;
  • lățimilor;
  • diametrelor;
  • dimensiunilor corpurilor.

De exemplu:

l=5 ml = 5\,\mathrm{m}l=5m d=2,5 md = 2{,}5\,\mathrm{m}d=2,5m

Kilogramul — unitatea de măsură pentru masă​

Unitatea fundamentală pentru masă este kilogramul.

[m]=kg[m] = \mathrm{kg}[m]=kg

Kilogramul este utilizat pentru măsurarea masei corpurilor.

Exemple:

m=5 kgm = 5\,\mathrm{kg}m=5kg m=250 gm = 250\,\mathrm{g}m=250g

Deoarece kilogramul este unitatea fundamentală pentru masă:

1 kg=103 g1\,\mathrm{kg} = 10^3\,\mathrm{g}1kg=103g

Secunda — unitatea de măsură pentru timp​

Unitatea fundamentală pentru timp este secunda.

[t]=s[t] = \mathrm{s}[t]=s

Secunda este utilizată pentru măsurarea duratei fenomenelor fizice.

Exemple:

t=10 st = 10\,\mathrm{s}t=10s t=2 min=120 st = 2\,\mathrm{min} = 120\,\mathrm{s}t=2min=120s t=1 h=3600 st = 1\,\mathrm{h} = 3600\,\mathrm{s}t=1h=3600s

Amperul — unitatea de măsură pentru intensitatea curentului electric​

Unitatea fundamentală pentru intensitatea curentului electric este amperul.

[I]=A[I] = \mathrm{A}[I]=A

Amperul este utilizat pentru măsurarea intensității curentului electric care circulă printr-un circuit.

Exemple:

I=2 AI = 2\,\mathrm{A}I=2A I=500 mAI = 500\,\mathrm{mA}I=500mA

Kelvinul — unitatea de măsură pentru temperatura termodinamică​

Unitatea fundamentală pentru temperatura termodinamică este kelvinul.

[T]=K[T] = \mathrm{K}[T]=K

Relația dintre temperatura exprimată în grade Celsius și temperatura exprimată în kelvini este:

T(K)=t(∘C)+273,15T(\mathrm{K}) = t(^{\circ}\mathrm{C}) + 273{,}15T(K)=t(∘C)+273,15

De exemplu:

0 ∘C=273,15 K0\,^{\circ}\mathrm{C} = 273{,}15\,\mathrm{K}0∘C=273,15K

Molul — unitatea de măsură pentru cantitatea de substanță​

Unitatea fundamentală pentru cantitatea de substanță este molul.

[n]=mol[n] = \mathrm{mol}[n]=mol

Un mol conține exact:

NA=6,022 140 76×1023N_A = 6{,}022\,140\,76 \times 10^{23}NA​=6,02214076×1023

entități elementare.

Numărul NAN_ANA​ se numește constanta lui Avogadro.

Candela — unitatea de măsură pentru intensitatea luminoasă​

Unitatea fundamentală pentru intensitatea luminoasă este candela.

[Iv]=cd[I_v] = \mathrm{cd}[Iv​]=cd

Candela este utilizată pentru caracterizarea intensității luminoase a unei surse de lumină.

Exemplu:

Iv=10 cdI_v = 10\,\mathrm{cd}Iv​=10cd

Prefixele unităților de măsură

Prefixele SI sunt utilizate pentru exprimarea multiplilor și submultiplilor unităților de măsură.

Un prefix modifică unitatea de măsură printr-o putere a lui 101010.

De exemplu:

1 km=103 m1\,\mathrm{km} = 10^3\,\mathrm{m}1km=103m

iar:

1 mm=10−3 m1\,\mathrm{mm} = 10^{-3}\,\mathrm{m}1mm=10−3m

Unitatea fără prefix corespunde factorului:

Exemple de utilizare

Kilometru​

Prefixul kilo corespunde factorului:

10310^3103

Prin urmare:

1 km=103 m1\,\mathrm{km} = 10^3\,\mathrm{m}1km=103m

adică:

1 km=1000 m1\,\mathrm{km} = 1000\,\mathrm{m}1km=1000m

Centimetru​

Prefixul centi corespunde factorului:

10−210^{-2}10−2

Prin urmare:

1 cm=10−2 m1\,\mathrm{cm} = 10^{-2}\,\mathrm{m}1cm=10−2m

adică:

1 cm=0,01 m1\,\mathrm{cm} = 0{,}01\,\mathrm{m}1cm=0,01m

Milimetru​

Prefixul milli corespunde factorului:

10−310^{-3}10−3

Prin urmare:

1 mm=10−3 m1\,\mathrm{mm} = 10^{-3}\,\mathrm{m}1mm=10−3m

adică:

1 mm=0,001 m1\,\mathrm{mm} = 0{,}001\,\mathrm{m}1mm=0,001m

Micrometru​

Prefixul micro corespunde factorului:

10−610^{-6}10−6

Prin urmare:

1 μm=10−6 m1\,\mathrm{\mu m} = 10^{-6}\,\mathrm{m}1μm=10−6m

Nanometru​

Prefixul nano corespunde factorului:

10−910^{-9}10−9

Prin urmare:

1 nm=10−9 m1\,\mathrm{nm} = 10^{-9}\,\mathrm{m}1nm=10−9m

Regula generală de conversie

Dacă un prefix corespunde puterii 10n10^n10n, atunci:

1 unitate cu prefix=10n unita˘ți fa˘ra˘ prefix1\,\text{unitate cu prefix} = 10^n\,\text{unități fără prefix}1unitate cu prefix=10nunita˘ți fa˘ra˘ prefix

De exemplu, pentru prefixul kilo:

n=3n = 3n=3

deci:

1 km=103 m1\,\mathrm{km} = 10^3\,\mathrm{m}1km=103m

Pentru prefixul milli:

n=−3n = -3n=−3

deci:

1 mm=10−3 m1\,\mathrm{mm} = 10^{-3}\,\mathrm{m}1mm=10−3m

Atenție la simboluri

Simbolurile prefixelor sunt sensibile la litere mari și mici.

De exemplu:

1 Mm=106 m1\,\mathrm{Mm} = 10^6\,\mathrm{m}1Mm=106m

în timp ce:

1 mm=10−3 m1\,\mathrm{mm} = 10^{-3}\,\mathrm{m}1mm=10−3m

Prin urmare, M și m reprezintă lucruri complet diferite:

M=106\boxed{\mathrm{M} = 10^6}M=106​m=10−3\boxed{\mathrm{m} = 10^{-3}}m=10−3​
